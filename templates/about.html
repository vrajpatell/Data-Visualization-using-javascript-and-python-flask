About QuakeRisk

QuakeRisk is a Flask, SQLite, Chart.js, Leaflet, and globe.gl application for monitoring USGS GeoJSON earthquake feeds.

Scientific limitation

Earthquake prediction is not scientifically reliable. This project only provides probabilistic earthquake forecasting, regional risk scoring, magnitude likelihood estimation, and aftershock/seismic activity trend analysis for education and situational awareness.

Deployment

Render can run the app with gunicorn main:app --bind 0.0.0.0:$PORT. SQLite works by default, but free instances may lose local cache data on restart unless a persistent disk or external database is configured.
